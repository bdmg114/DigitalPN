# 입력 설계

## 1. 키 배열

```
 [왼쪽 어깨: Shift]                                [오른쪽 어깨: 기호]

  ㅂ  ㅈ  ㄷ  ㄱ  ㅅ   ┌────────┐   ㅛ  ㅕ  ㅑ  ㅐ  ㅔ
  ㅁ  ㄴ  ㅇ  ㄹ  ㅎ   │        │   ㅗ  ㅓ  ㅏ  ㅣ  ⌫
  ㅋ  ㅌ  ㅊ  ㅍ  ㅠ   │  화면  │   ㅜ  ㅡ  ,   .   ↵
  메뉴 한/영 [ 스페이스 ] │        │  [ 스페이스 ] ◀  ▶
                       └────────┘
```

영문 모드에서는 같은 자리가 QWERTY다 (`QWERT / YUIOP`, `ASDFG / HJKL`, `ZXCVB / NM`).

- 글자 30자리는 표준 두벌식·QWERTY와 같다. 새로 외울 것은 ⌫, ↵, 쉼표·마침표 위치뿐이다.
- 스페이스 바는 양쪽에 있다. 직전 글자를 친 엄지의 반대쪽으로 치면 교대가 유지된다.
- 기준 키(ㅇ, ㅓ 자리)의 키캡에는 돌기를 둔다.

## 2. 레이어: 검지가 전환하고 엄지는 글자만 친다

| 조작 | 동작 |
|---|---|
| 어깨 버튼을 누른 채 키 | 그 키에만 적용 |
| 어깨 버튼만 짧게 눌렀다 뗌 | 다음 한 글자에 적용 (원샷) |
| 어깨 버튼 두 번 연타 | 고정, 한 번 더 누르면 해제 |

**Shift (왼쪽 어깨)**: ㅃ ㅉ ㄸ ㄲ ㅆ, ㅒ ㅖ, 영문 대문자. `Shift + ↵` = 새 메모, `Shift + ◀ / ▶` = 항목 처음 / 끝.

**기호 (오른쪽 어깨)**

```
  1  2  3  4  5        6  7  8  9  0
  @  #  %  &  *        (  )  -  _  ⌫단어
  ~  ^  /  :  ;        "  '  ?  !  줄바꿈
```

- `기호 + ↵` = 항목 안에서 줄바꿈, `기호 + ⌫` = 단어 지우기
- `기호 + ◀ / ▶` = 이전 / 다음 항목
- `기호 + 한/영` = 항목 종류 바꾸기 (문단 → 할 일 → 제목)

**양쪽 어깨 동시 (기능)**

| 키 | 동작 |
|---|---|
| ↵ | 지금 전송 |
| ⌫ | 현재 항목 삭제 |
| ◀ / ▶ | 이전 / 다음 메모 |
| 스페이스 | 할 일 완료 표시 전환 |
| 메뉴 (2초) | 전원 끄기 |

쌍자음을 길게 눌러 입력하는 방식(기본 꺼짐, 180 ms)도 설정으로 제공한다. 같은 자음을 두 번 쳐서 쌍자음을 만드는 방식은 쓰지 않는다. "국가"처럼 같은 자음이 이어지는 말이 깨지기 때문이다.

## 3. 항목과 메모

- `↵` : 현재 항목을 끝내고 같은 메모에 새 항목을 연다.
- 빈 항목에서 `↵` (즉 두 번 연속) 또는 `Shift + ↵` : 새 메모를 시작한다.
- 본문 안의 `#단어`는 태그로 추출된다.

한 번의 엔터가 곧 저장 단위이자 전송 단위다. 문단을 나누는 평소 습관이 그대로 데이터 구조가 된다.

## 4. 한글 조합

[`firmware/core/hangul.c`](../firmware/core/hangul.c)에 구현되어 있고 호스트에서 테스트된다.

- 초성 → 중성 → 종성 순의 두벌식 오토마타
- 겹모음(ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ), 겹받침(ㄳ ㄵ ㄶ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅄ)
- 받침 뒤에 모음이 오면 받침이 다음 글자의 초성으로 넘어감. 겹받침은 둘째 자음만 넘어감 (`달ㄱ + ㅏ → 달가`, `갑ㅅ + ㅣ → 갑시`)
- 조합 중 백스페이스는 자모 단위, 조합이 끝난 글자는 글자 단위

## 5. 속도와 정확도를 위한 처리

| 처리 | 내용 |
|---|---|
| 스캔 | 타자 중 1 kHz 매트릭스 스캔. 대기 중에는 인터럽트로 깨어남. |
| 선(先)등록 디바운스 | 눌림은 첫 접점 변화에서 즉시 등록하고 이후 5 ms 동안만 그 키의 변화를 무시한다. 디바운스가 지연을 더하지 않는다. |
| 누른 순서대로 처리 | 키를 뗄 때가 아니라 누를 때 입력한다. 두 엄지가 겹쳐 눌러도(롤오버) 순서가 보존된다. 모든 키에 다이오드가 있어 동시 입력 수 제한이 없다. |
| 걸침 필터 (실험, 기본 꺼짐) | 인접한 두 키가 8 ms 안에 함께 눌리고 하나가 30 ms 안에 떨어지면 엄지가 두 키에 걸친 것으로 보고 먼저 눌린 키만 받는다. 0단계 로그로 임계값을 정한다. |
| 자동 교정 없음 | 친 대로 들어간다. 예측·자동 수정은 기본 제공하지 않는다. 영문 문장 첫 글자 대문자만 선택 사항. |
| 지연 목표 | 키 누름 → 화면 반영 20 ms 이내 (스캔 1 + 조합 1 미만 + 바뀐 글자 줄만 다시 그리기 약 5 ms) |

## 6. 타건 측정 모드

배열과 임계값을 감이 아니라 숫자로 다듬기 위해 펌웨어에 측정 모드를 둔다. 메뉴에서 켜면 다음을 기록하고 내용은 기록하지 않는다.

- 분당 타수, 백스페이스 비율
- 키별 누름 횟수와 직후 백스페이스 비율 (어느 키에서 오타가 나는지)
- 연속 두 키 사이 시간의 좌우 교대 / 같은 손 분포

결과는 `/stats.json`으로 저장되어 USB로 꺼낼 수 있다.
